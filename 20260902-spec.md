# 个人开发者工具网站开发需求文档

**文档版本：** v1.0  
**项目定位：** 免费、轻量、隐私优先的在线开发者工具网站  
**核心目标：** 提供一站式 Developer Tools，并通过工具页面与技术文章形成内容与工具闭环。

---

# 1. 项目概述

## 1.1 产品定位

建设一个面向开发者的在线工具网站：

> **Developer Tools / AI Tools / Data Tools / Linux Tools / DevOps Tools / Web3 Tools**

核心特点：

- 免费使用
- 打开即用
- 无需登录
- 优先纯前端实现
- 用户数据优先在浏览器本地处理
- 简洁、专业、开发者友好的 UI
- 每个工具拥有独立 URL
- SEO 友好
- 工具与技术文章互相导流

# 4. 产品原则

## 4.1 使用原则

```text
打开即用
输入即处理
结果清晰
一键复制
无需注册
```

用户进入工具页面后：

> **5 秒内能够理解如何使用。**

---

## 4.2 技术原则

优先级：

```text
纯前端
  >
Serverless
  >
Backend
```

能浏览器计算：

> 不上后端。

能静态数据：

> 不上数据库。

只有以下情况才使用 API：

- 实时 Web3 数据
- LLM API
- 实时价格
- 实时 Gas
- 外部数据查询

# 27. 性能要求

纯前端工具：

```text
首屏加载：< 2s
普通操作响应：< 100ms
普通数据处理：< 500ms
```

对于大文本：

```text
> 1MB
```

考虑：

- Web Worker
- Debounce
- Virtualization
- Incremental Processing
- Lazy Loading

避免大文本处理阻塞 UI。

# 38. 产品成功标准

网站不是追求：

> 工具数量越多越好。

而是追求：

```text
工具质量
   +
统一体验
   +
搜索流量
   +
开发者复用
   +
低运营成本
```

最终形成：

```text
                  Developer Tools Website
                           │
          ┌────────────────┼────────────────┐
          ↓                ↓                ↓
       Developer          Data             Linux
          │                │                │
          └────────────────┼────────────────┘
                           ↓
                         DevOps
                           ↓
                          AI
                           ↓
                         Web3
```

核心产品理念：

> **简单、快速、专业、隐私优先。**

> **能本地处理就本地处理，能静态实现就静态实现，只有真正需要实时数据时才使用 API。**

> **每一个工具都是一个独立产品页面，同时也是一个搜索入口。**
